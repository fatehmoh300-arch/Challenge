# حالة بيئة العمل والمستودع

آخر فحص للمستودع: 28 نوفمبر 2026.

## مصدر العمل

المستودع المرجعي هو `fatehmoh300-arch/Challenge`. الملفات المرفوعة بصيغة ZIP لقطات مصدرية للمراجعة فقط؛ قد تسبق الفروع الحالية ولا ينبغي نسخها فوق المستودع.

النسخة التي رُفعت في هذه المحادثة تتضمن تطبيقاً أولياً ثابتاً لشهر ديسمبر 2026، ولا تتضمن migrations المرنة اللاحقة أو بنية PR #5 وPR #6. لذلك لا تُستخدم تلك اللقطة كأساس لقرارات المنتج أو لاستبدال ملفات GitHub الحالية.

## وضع الفروع وطلبات الدمج عند الفحص

- `main`: يحتوي النسخة الأساسية الأقدم.
- PR #5: `feat/challenge-platform-foundation`، طلب مفتوح وغير مسودة، يحول المنتج إلى منصة متعددة التحديات.
- PR #6: `fix/challenge-security-scoring-integrity`، طلب مفتوح بحالة Draft، مبني على فرع PR #5 ويضم تدقيقات أمان وسلامة نقاط إضافية.
- أحدث رأس تمت مراجعته في PR #6 وقت الفحص: `9a280f2b0e8e85aa63d77f2c0bcc74d392281fa8`.
- وصف PR #6 يسجل نجاح 29 اختبار قواعد عمل، ونجاح npm audit دون ثغرات، وفحص TypeScript، وبناء الإنتاج. يظل PR مسودة حتى تكتمل اختبارات القبول المنفصلة.

هذه الحالة مرتبطة بتاريخ الفحص؛ راجع GitHub قبل اتخاذ أي خطوة دمج أو إعادة تأسيس فرع.

## قاعدة البيانات

- يذكر تقرير PR #6 أن 14 migration مسجلة ومطابقة لأسماء الملفات المحلية في فرع الإصلاح.
- التحدي القائم «صلاة الفجر» وسجلاته يجب الحفاظ عليها.
- لا تُشغّل migrations مجدداً، ولا تستخدم `supabase db push`، قبل مطابقة سجل البيئة المستهدفة ومخططها.
- يوجد قيد موثق: دور الاستضافة المتاح لم يسمح بتعديل default ACL للمالكين `postgres` و`supabase_admin`. لذلك يجب مراجعة grants لأي جدول أو دالة جديدة صراحةً.

## ما تبقى قبل اعتماد الإطلاق

1. إنهاء مراجعة PR #6 وتحويله من Draft بعد تحقق مستقل.
2. اختبارات قبول بحسابات منفصلة للمالك والمساعد والمشرف والعضو وغير العضو.
3. اختبار دعوات وطلبات انضمام ومشاركات وتعليقات بين التحديات.
4. اختبار Android فعلي للواجهات الأساسية.
5. اختبار حمل واقعي يقترب من هدف 50 مشاركاً قبل ضمانه.
6. مراجعة إعداد حماية كلمات المرور المسربة في Supabase Auth.
7. معالجة/توثيق قيود lockfile وإعادة إنتاج بيئة التبعيات.

## إعدادات بيئة التطوير التي أضيفت

- Node.js 22 عبر `.nvmrc` و`engines`.
- إعداد موحد للمحررات ونهايات الأسطر.
- تعليمات عمل للمساعدات البرمجية في `AGENTS.md`.
- دليل قرارات المنتج، سير العمل، وبوابات الجودة.
- أداة `npm run doctor` لفحص متطلبات البيئة دون كشف قيم الأسرار.

هذه الإضافات لا تغير سلوك التطبيق أو بيانات Supabase.
