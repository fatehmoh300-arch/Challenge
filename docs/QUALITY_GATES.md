# بوابات الجودة والقبول

لا تُعد الميزة جاهزة لمجرد أن الصفحة تُحمّل. استخدم البوابات المناسبة بحسب مساحة التغيير.

## الفحوص المحلية

من جذر المشروع:

```bash
npm install
npm run doctor
npm run test:rules
npm run typecheck
npm run build
npm audit --audit-level=high
```

يمكن استخدام `npm run check` لتشغيل فحوص الأساس معاً. البناء والإعدادات الحية يظلان فحصين منفصلين.

## قبول المصادقة والتحديات

- إنشاء حساب وتسجيل الدخول وتسجيل الخروج.
- استعادة كلمة المرور والعودة عبر `/auth/callback`.
- إنشاء تحدٍ جديد بفترة وإعدادات صحيحة، دون إنشاء أهداف غير مطلوبة تلقائياً.
- الانضمام العام، والانضمام بدعوة، وطلب الانضمام الذي يحتاج موافقة.
- التبديل بين تحديات الحساب دون تسرب بيانات تحدٍّ إلى آخر.
- اختبار الحدود الزمنية: قبل البداية، داخل المدة، يوم النهاية، وبعد الإكمال.

## مصفوفة الصلاحيات

اختبر بحسابات مستقلة أو جلسات منفصلة:

- المالك.
- مساعد بصلاحيات محددة.
- مشرف بصلاحيات محددة.
- مشارك عادي.
- مستخدم غير عضو.

تحقق من السماح والرفض لكل إجراء، خاصة إدارة الأعضاء، تعديل القواعد، اعتماد طلبات الانضمام، نشر الإعلان الرسمي، إكمال التحدي وأرشفته. لا تعتمد على إخفاء الأزرار؛ يجب أن ترفض قاعدة البيانات العملية غير المصرح بها.

## سلامة النقاط والترتيب

- لا يستطيع العميل كتابة مجموع النقاط أو XP.
- تُحفظ نقاط الإنجاز وقت التسجيل.
- تعديل هدف أو إيقافه لا يعيد كتابة النقاط التاريخية.
- الأهداف الإلزامية والاختيارية تؤثر كما هو محدد.
- التعادل ينتج مراكز مشتركة ولا يُحسم بالاسم أو UUID.
- لا تُمنح الجوائز أكثر من مرة، ولا يعاد فتح تحدٍّ مكتمل بطريقة تغيّر نتائجه.

## الخصوصية

- سجلات الإنجازات والقراءة والملاحظات الشخصية لا تُكشف لمشارك آخر.
- لوحة المنافسة لا تستخدم إلا الإحصاءات المسموح بها.
- التحديات الخاصة غير مرئية لغير المخولين.
- مستويات ظهور الملف الشخصي تُطبق على القراءة الفعلية للبيانات.
- اختبر روابط الدعوة والرموز دون كشفها من جداول القراءة المباشرة.

## الهاتف والأداء

- اختبر العرض على شاشة هاتف ضيقة واتجاه RTL.
- اختبر القوائم والنوافذ والنماذج والتنقل باللمس.
- نفذ اختبار قبول مع 2 حسابين حقيقيين، ثم اختبار تجريبي يقارب 50 مشاركاً قبل ضمان هذا الهدف.
- السعة النظرية في قاعدة البيانات لا تعني أن الأداء عند 50 أو 500 مستخدم تم إثباته.

## ما لا يجوز ادعاؤه

لا تصف التطبيق بأنه يعمل بالكامل دون اتصال، أو يرسل Push بعد إغلاقه، أو يضمن سعة 50/500 مشارك، أو اكتمل رفع الصور، إلا بعد تنفيذ واختبار هذه الوظائف صراحة.
